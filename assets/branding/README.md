# Solomon AI Orchestrator -- Branding Assets

Branding assets for the v0.4.0-alpha release. All files are PNG with a
real alpha channel (transparent background); metadata has been stripped.

| File | Size (px) | Use |
|---|---|---|
| `solomon-logo.png` | 1305 x 470 | Primary logo: symbol + "SOLOMON / AI ORCHESTRATOR" (README header) |
| `solomon-wordmark.png` | 435 x 210 | Wordmark only, gold |
| `solomon-icon-512.png` | 512 x 512 | App/avatar icon (rounded square) |
| `solomon-icon-256.png` | 256 x 256 | Icon |
| `solomon-icon-128.png` | 128 x 128 | Icon |
| `solomon-icon-64.png` | 64 x 64 | Icon / favicon-scale |

Notes:

- The artwork was produced with an image-generation tool and cropped
  from a single composition. Edges may show minor generation artifacts
  at large zoom.
- The icon sizes are derived from one source crop; the 512 px version
  is upscaled and is softer than a native vector export would be.
- Japanese-typography variants and a dedicated dark/light README header
  are not included in this release; the candidate crops were truncated
  and did not meet the bar for official use. The design brief lives at
  `docs/specification/09_Branding/Branding_and_Logo_Brief.md`.
