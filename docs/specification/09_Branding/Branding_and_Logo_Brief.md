# Solomon Branding Brief v0.4

Progress: 100% brief / 0% final artwork

## Brand idea
Solomon is not a chatbot. It is a quiet orchestration core coordinating specialized AI systems.

## Visual direction
- Central core / seal / node.
- Multiple controlled satellite nodes.
- Subtle geometric "Solomon" motif without becoming fantasy-heavy.
- Developer infrastructure / open-source / orchestration feel.
- Must work on GitHub light and dark themes.
- Avoid generic glowing AI brain imagery.

## Required assets
- Primary symbol
- Horizontal wordmark: Solomon AI Orchestrator
- GitHub avatar
- README header/banner
- Favicon/app icon
- CLI ASCII mark
- Monochrome version
- Transparent PNG
- SVG/vector master

## Logo concepts to explore
A. Orchestration Seal - central node + six linked nodes in a precise geometric seal.
B. S-Monogram Router - abstract S built from branching/merging routes.
C. Crown/Core Network - understated crown geometry above a central routing core.

## Tone
Technical, calm, precise, extensible, trustworthy.
